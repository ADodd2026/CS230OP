# CS230OP
CS230 Operating Platforms

The Gaming Room was a client that was looking to expand their reach to different platforms for the already existing game. Draw It or Lose It was going to be based across all platforms, and now wanting to extend their reach into a web-based application. Their application needed to be able to support multiple games, teams, and players while maintaining the unique ID features. The client also wanted the game to be accessible from different devices without running into any compatability options. I think going through the software design document and comparing which operating platform would work best for the client was alright. I was definitely looking at the advantages and disadvantages of Linux primarily but also considering the client's requirements by looking at Windows and Mac also. One thing that I think was helpful for this assignment was being able to organize the structure of the application before going deeper into the coding aspect of the assignment. Designing the UML made it easier to understand how different classes connect and what they are each responsible for. If there was an aspect that I could go back and redo or add more information to, I think I would go back to the security and storage section, I think that I did well covering the basic concepts but I think that if i were to have provided more specific examples of how the user information and game data were protected, it would have improved the overall design.

I was interpreting the users needs by focusing primarily on accessibility, compatibility, and keeping the application organized. Because The gaming room wanted to be able to have the application running simutaneously through multiple platforms, I highly recommended linux since that would be the easiest option for accessibility through the server for a web application. Considering the user's needs were important also since the application needed to function properly and meet the expectation of the users who will be using the application. My first approach was to understand the requirements of the client and then break down the different components of which the client was asking for the application to be completed. I was able to compare multiple operating platforms, design the UML, and considered how the application would be able to handle user and game data which is sensitive.
